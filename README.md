# Taskagotchi — Productivity Web App

Taskagotchi is a team-built productivity application combining task management with a 3D game interface.

The frontend uses React, TypeScript, Vite, and React Three Fiber. The backend uses Flask, PostgreSQL, SQLAlchemy, and database migrations. The repository includes frontend component tests and backend API tests.

## Repository structure

- [`productivity-frontend/`](productivity-frontend/) — interface, game components, task and account pages, and frontend tests
- [`productivity-backend/`](productivity-backend/) — Flask API, database models and migrations, Docker setup, and backend tests

See each folder's README for development setup and run instructions.
